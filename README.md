# Website Kelas PPLG 2 Angkatan 16

Domain: **pplg2angkatan16.web.id**

Website resmi kelas Pengembangan Perangkat Lunak dan Gim (PPLG) 2 Angkatan 16.

## Struktur File

```
pplg2-website/
├── index.html          → Halaman utama
├── anggota.html        → Daftar anggota kelas
├── proyek.html         → Daftar proyek
├── galeri.html         → Galeri foto
├── css/
│   └── style.css       → Styling utama
├── js/
│   └── script.js       → Interaktivitas
└── assets/             → Taruh foto & gambar di sini
```

## Cara Pakai

1. Upload semua file ke hosting (Netlify, Vercel, atau hosting biasa).
2. Arahkan domain `pplg2angkatan16.web.id` ke folder ini.
3. Ganti data placeholder:
   - Nama anggota di `anggota.html`
   - Foto di folder `assets/` lalu hubungkan di `galeri.html`
   - Detail proyek di `proyek.html`

## Fitur

- Responsive (mobile & desktop)
- Dark theme techy (cocok jurusan PPLG)
- Animasi ringan saat scroll
- Mobile menu
- Siap dikembangkan lebih lanjut

## Catatan Domain

Domain memakai **angkatan16** (bukan 11pplg2) supaya tetap relevan sampai kelas 12 dan seterusnya.
